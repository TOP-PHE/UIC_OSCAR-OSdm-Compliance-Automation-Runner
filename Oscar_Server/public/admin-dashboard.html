📊 Admin Dashboard

Operational tooling for OSCAR. Each tile opens in a new tab; sign-in is single-sign-on through your OSCAR session.

⚠️ The admin observability stack is restricted to administrator accounts. You may see authentication errors when clicking the tiles below.
📈
Grafana
Live operational dashboards — HTTP latency, run throughput, queue depth, process resources. Comes with the OSCAR · Overview dashboard out of the box; build more in the Grafana UI.

Prometheus
Raw metrics database. Useful for ad-hoc PromQL queries, scrape-target health (/prometheus/targets), and confirming the ingestion path when a Grafana panel looks wrong.

Logs (Loki)
Centralised log aggregation across OSCAR + Bruno workers. Pre-built "OSCAR · Logs" dashboard with errors-only view, full live tail, and per-container filter. Free-form LogQL queries available in Grafana's Explore tab.
Open Logs →

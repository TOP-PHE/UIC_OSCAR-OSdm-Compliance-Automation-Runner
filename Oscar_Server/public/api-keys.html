🔑 API Keys

What an API key is

An API key lets a program read the run results of the company or provider chosen in Working on: a dashboard, a script, a CI job. It can only read, it sees the runs of that one company or provider, and it works on the /v1/api routes only. It stops when it expires, when it is revoked, or when the Test Manager who made it is no longer one.

Named suites

A suite is a selection saved under a name. Your company's test automation asks it by name through the API (POST /v1/api/test-requests with "suite"), and its filters are applied on each provider at each launch. Saved with My run list, it runs each provider's own run list (its Test Config selection), shared scenarios only.
